#  TaskFlow – Application de gestion de projets (Kanban)

TaskFlow est une application web moderne de gestion de projets basée sur la méthode **Kanban**.  
Elle permet de créer des projets, d’organiser des tâches et de suivre leur progression de manière visuelle, intuitive et efficace.

## 🧠 Méthodologie utilisée

L’application est basée sur la **méthode Kanban**, qui repose sur :
- La visualisation du travail
- La limitation du travail en cours
- L’amélioration continue

Les tâches sont organisées en colonnes :
- 📝 À faire  
- ⚡ En cours  
- ✅ Terminé  

---

## ✨ Fonctionnalités principales

- 🔐 Authentification (Login / Register)
- 👤 Connexion avec Google
- 📁 Création et modification de projets
- 🎨 Personnalisation des projets (couleurs)
- 🧱 Tableau Kanban interactif
- 📝 Gestion des tâches (ajout, modification, suppression)
- 📊 Suivi de la progression des projets
- 💎 Interface moderne (UI/UX)
